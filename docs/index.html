CCS 앞단에서 모델 라우팅을 정리한다.

Claude Code CLI와 VS Code Copilot BYOK 요청을 받아 thinking 모델, Codex effort suffix, 일반 passthrough를 분리한 뒤 CCS의 올바른 provider endpoint로 넘기는 작은 프록시입니다.

Provider responsestreamed back through the same interface

세 가지 요청 경로.

Thinking

claude-*-thinking 모델에 thinking payload를 주입하고 token cap을 맞춥니다.

Codex effort

*-xhigh, *-high 같은 suffix를 reasoning effort로 바꿔 Codex endpoint로 보냅니다.

Passthrough

그 외 모델은 CCS로 그대로 전달해 기존 provider 라우팅을 유지합니다.

CCS가 먼저 실행 중이어야 한다.

Install

pip install -r requirements.txt로 FastAPI, Uvicorn, HTTPX를 설치합니다.

Run

python3 thinking-wrapper.py --port 8318로 wrapper를 띄웁니다.

Connect

ANTHROPIC_BASE_URL=http://localhost:8318로 Claude Code를 연결합니다.

검증과 상태.

Syntax

python3 -m py_compile thinking-wrapper.py로 단일 파일 proxy 문법을 확인합니다.

Health

curl http://localhost:8318/health는 CCS가 먼저 켜져 있을 때 의미가 있습니다.
